# GSheYog 🧘

A comprehensive Yoga companion app built with Flutter. Learn Body Yoga & Face Yoga with guided video tutorials, pose breakdowns, and health benefits.

## Features

- **Body Yoga** - 10+ poses from beginner to advanced with detailed instructions
- **Face Yoga** - 6 facial exercises for natural anti-aging and toning
- **Video Classes** - In-app YouTube player with curated classes from top instructors
- **Benefits Guide** - Learn why yoga transforms your health
- **Earthy Design** - Warm, natural color palette inspired by nature

## Getting Started

```bash
git clone https://github.com/vanshulchawla-wq/GSheYog.git
cd GSheYog
flutter pub get
flutter run
```

## Tech Stack

- Flutter 3.7+
- YouTube Player Flutter (in-app video playback)
- Google Fonts (Playfair Display + Lato)
- Cached Network Image
- No backend required - all data is local
